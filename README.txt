# Telangana School Grants — 2026–27

## Files
- `index.html`: responsive grant report app, 7 printable report tabs, today’s date, reset button, district/mandal filters, UDISE search, DDO name/designation/code, editable bank details and reference text.
- `schools-data.js`: embedded school-level grant records extracted from the supplied Composite and Sports grant Excel workbooks.

## Publish as a new free website using GitHub Pages
1. Sign in at https://github.com/new
2. Create a **new public repository** named `telangana-school-grants-2026`.
3. Upload both `index.html` and `schools-data.js` into the repository root.
4. Open **Settings → Pages**.
5. Under Build and deployment choose **Deploy from a branch**, branch `main`, folder `/ (root)`, then Save.
6. After publishing, the new URL will be `https://YOUR-GITHUB-USERNAME.github.io/telangana-school-grants-2026/`.

The new link depends on the GitHub username/repository owner. Do not use a made-up URL before publishing.
